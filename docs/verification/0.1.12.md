# Wayfarer 0.1.12 verification

Reviewed against the official [plugin guidelines](https://docs.obsidian.md/Plugins/Releasing/Plugin+guidelines), [developer policies](https://docs.obsidian.md/Community+directory/Developer+policies), [submission requirements](https://docs.obsidian.md/Community+directory/Submission+requirements+for+plugins), and [pop-out window guidance](https://docs.obsidian.md/Plugins/Guides/Support+pop-out+windows).

- Uses the plugin's app reference, registered events and cleanup callbacks, workspace-owned view lifetimes, and conditional command callbacks.
- Uses the Editor API for active edits and Vault.process for Reading-view writes, with original-file and stale-result guards. Constructed vault paths are normalized.
- Does not detach saved map leaves during unload. Pending editor debounce is canceled, queued routes are discarded, and late results cannot write to notes.
- Map chrome queries and interactions use the view's document/window and cross-window DOM type checks.
- Uses Obsidian requestUrl for network adapters. The shipped bundle has no Node or Electron runtime imports. Short-link expansion reads destination URLs from Google's response without executing page scripts.
- README discloses map tiles, Google network requests, API billing, key storage, version compatibility and short-link fallback behavior.

## Validation

`pnpm check` passed with zero lint warnings, CSS lint, TypeScript, 141 tests in 13 files, production build and bundled-plugin smoke. The smoke exercises mobile short-link conversion without Node, source/Reading-view writes, original business links, repeat conversion, edited links, request limits, unload cleanup and workspace view lookup.

In an isolated temporary vault on actual Obsidian 1.11.7, version 0.1.12 loaded and rendered the itinerary. A popup's store link retained the original href; its click handler was observed with window.open temporarily captured so QA did not open an external browser. Disabling and re-enabling the plugin disposed the old router and restored exactly one map leaf. A real maps.app.goo.gl URL resolved using requestUrl without a key, saved its coordinates and original href, and retained that href in the rendered Reading view.

Physical iOS/Android validation was not performed. Short-link expansion can be blocked by Google's consent/anti-bot response; the original pasted link remains available and the user can supply a full place URL.
